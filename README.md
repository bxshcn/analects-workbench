# 《论语》知识图谱工作台

本项目以《论语》原典为核心，用知识图谱与交互式索引连接人物、概念与章句，面向经典学习、课堂教学与数字人文研究。你可以：

- 在人物关系弦图中观察谁赞美谁、谁批评谁、谁品评谁；
- 沿概念索引按关系与方向查找相关人物与章句；
- 回到原文，阅读译文/训诂、注释、疏解与评析。

我们希望降低查检与理解《论语》的门槛，让读者从关系与语境中重新进入经典。

## 快速开始

```bash
npm install
npm run dev
```

启动后打开终端提示的本地地址（默认 http://localhost:5173）。首次运行会自动根据 `src/data` 生成所需数据包。

## 参与数据修订

《论语》章句、人物关系、概念释义与注疏内容集中在 `src/data/` 目录。欢迎针对这些数据提交 Pull Request，也欢迎通过 Issue 指出错误或补充材料。

提交前请阅读 [`src/data/README.md`](src/data/README.md) 中的字段说明与校验规则，并在本地运行：

```bash
npm run data:check
```

确认校验通过后再提交。
